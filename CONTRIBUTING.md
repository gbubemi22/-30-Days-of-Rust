# Contributing

Thanks for helping improve 30 Days of Rust. The course is written for readers who may be new to programming, so explain technical terms before relying on them.

## Lessons

Each lesson should include:

- a short introduction and learning objectives;
- prerequisites and accurate, beginner-friendly explanations;
- small syntax examples and a runnable demonstration with run instructions;
- expected output when useful;
- common mistakes, exercises, and further reading;
- previous/next links and a link to the course index.

Keep exercises separate from worked solutions. Prefer the standard library when it is sufficient, and explain why an external crate is included when one is needed. Use original teaching text and examples; do not copy lesson text or assets from another course.

## Code and review

Use stable Rust and format code with rustfmt. Before submitting a change, run the relevant Cargo checks and compile standalone examples affected by the change. Keep documented output in sync with the example. Do not include real credentials, generated build directories, or unrelated files.

## Pull requests

Describe what changed, which lessons or examples it affects, and what checks you ran. For incomplete material, state what remains so the course progress is clear.
